# EAi Studio · TEST Mini App 0.55

Public static frontend only. Main bot sources, credentials and databases belong in the separate private repository.

The interface uses the owner's original EAi Post Studio and EAi Support logos, a dark blue/cyan/violet palette, quick editor actions and seven copyable post starters. The former Support report import and report screen have been removed.

Open through the TEST bot's reply keyboard to use Telegram.WebApp.sendData. Direct browser visits offer a link to the TEST bot. Actions are allowlisted and pass the bot's normal access/subscription checks. The webpage does not grant admin access or display private analytics.

Public files: index.html, style.css, app.js, README.md, .nojekyll, studio-logo.jpg, support-logo.jpg. No external analytics or private API endpoint.
